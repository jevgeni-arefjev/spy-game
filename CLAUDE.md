# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

**Spy** - a mobile-first, pass-and-play party game for one shared phone. One
player is secretly the spy; everyone else sees the same word. Five minutes of
discussion, then "Time's up" - the round ends at the timer, with no voting,
scoring or elimination.

The flow is `home → topics → players → reveal → discussion → ended`. Topics are
word sets the group includes or excludes (at least one, up to all); the word is
drawn from the union. The roster, topic selection and spy count are remembered
and stay editable between games - "Play again" returns to topics, "Exit" returns
home, and neither wipes them.

- [DESIGN.md](DESIGN.md) - normative for anything visual; read it before

## Commands

```shell
npm run dev            # dev server
npm run build          # tsc -b && vite build — this is the type-check
npm run lint           # eslint
npm test               # vitest run — the game/ and lib/ unit suite
npm run test:watch     # vitest in watch mode
npm run preview        # serve dist/
npx vitest run src/game/reducer.test.ts   # a single test file
```

`npm test`, `npm run build` and `npm run lint` are the three gates; run all
three before calling anything done. Tests are `*.test.ts` files sitting next to
the module they cover, under `src/game/` and `src/lib/`, and cover pure logic
only - no component or DOM tests, so Vitest runs in the `node` environment with
no jsdom.

## Layout

Under `src/`: `game/` is the domain (reducer, round, topics, words, persistence,
config, context); `lib/` is helpers with no React and no game rules; `screens/`
is one file per phase; `styles/` holds `tokens.css` (the visual source of
truth), `motion.css`, `fonts.css`, `tokens.ts`, `global.css`; plus
`components/`, `i18n/` and `assets/`.

Each component has its `.module.css` next to it. Imports are relative; there are
no path aliases. Full-size PNG sources for the WebP assets live in `assets/` at
the repo root.

## Conventions

- TypeScript strict, plus `noUnusedLocals` / `noUnusedParameters`.
- No semicolons, single quotes, two-space indent - matching the boilerplate.
  There is no Prettier config; follow the surrounding file.
- Named exports everywhere except `App`, which stays a default export because
  `main.tsx` imports it that way.
- Components and hooks live in separate files from the contexts they use, so
  `react-refresh/only-export-components` stays quiet.

## Rules that must not be broken

Each is explained in [docs/architecture.md](docs/architecture.md).

- **One state machine.** `useReducer` + context, no state library.
  `src/game/reducer.ts` is the only place state changes, and every action guards
  on the current phase.
- **The reducer is pure.** Never call `Math.random()` or `Date.now()` inside it;
  draw them in `createRoundSetup()` (`src/game/round.ts`) and pass them in the
  action payload. StrictMode double-invokes reducers.
- **The timer is deadline-based.** State holds an absolute `endsAt` while
  running and `remainingMs` while paused; every frame recomputes from
  `Date.now()`. Never accumulate ticks.
- **No router.** Rendering is phase-driven, because this app is destined for a
  `file://` native shell.
- **All storage goes through `src/lib/storage.ts`** - no component may touch
  `localStorage`. Writes debounce ~200ms, flushed on `pagehide`/`visibilitychange`.
- **Stored state is validated, never repaired.** `parseStoredState()`
  (`src/game/persistence.ts`) checks version, shape *and* cross-field
  consistency; anything off is discarded and the app boots clean. A shape change
  means bumping `STATE_VERSION` and `STORAGE_KEY`'s suffix (currently `v4`).
- **Whether a card is face-up is not persisted.** A reload must not expose a
  role to whoever is holding the phone.
- **Every user-facing string goes through `t()`.** State stores `wordId` and
  `topicIds`, never translated text, so a mid-game language switch is safe.
- **The locale is chosen on the home screen only.** `<LanguagePicker>` renders
  nowhere else and `setLocale()` (`src/i18n/index.ts`) is its only writer - once
  the phone is being passed around, a stray corner tap must not relabel the game.
- **`src/game/topics.ts` is the single source of truth for topics and words.**
  Word ids are unique across topics; every topic runs on one binary adjective
  axis (exactly two `hintId`s), and that adjective is the spy's only clue.
- **The spy count is runtime state** (`spyCount` on `GameState`, set on the
  Players screen, clamped to `1 … players.length`; spies are a set, `spyIds`).
  `config.ts` only exports `DEFAULT_SPY_COUNT`.
- **A spy's card never says how many spies there are.** `role.spy.hint` is a
  single non-plural string and `RoleCard` takes no `spyCount`; do not
  reintroduce a plural there.
- **All visual constants live in `src/styles/tokens.css`**, split into raw
  `--palette-*` and semantic `--color-*`. Component CSS carries no hex colours,
  pixel values or font stacks; `public/favicon.svg` and `src/assets/card-back.svg`
  are the only exceptions (and take no XML comments - a `--` invalidates them).
- **There is one theme, on purpose.** `color-scheme: dark`, no
  `prefers-color-scheme` block. No light mode without the owner's sign-off.
- **Depth is the grammar of what can be touched.** A new control inherits the
  die-cut edge, shadow, press-sink and dashed-die-line disabled state from
  `Button` rather than restyling them.
- **Both faces are self-hosted** from `@fontsource` via `src/styles/fonts.css`.
  Nothing from a font CDN - the app must run offline and from `file://`.
- **The content column is pinned to `100dvh`, not grown past it.** `Screen` caps
  it and gives it its own `overflow-y`; the primary action is always last in it.
- **A phase change is a view transition, and nothing else is.** `GameProvider`
  starts one only for an action that actually changes phase, never while the
  page is hidden, and applies the action anyway after 200ms.

## Gotchas

- **Write an animation as `animation: var(--animation-*)`, never as a bare
  keyframe name.** CSS Modules scopes a bare name, the keyframes are global, and
  the animation then silently does not run while the element still looks right
  at rest.
- The countdown ring's `stroke-dashoffset` is **negative** - that is what opens
  the gap at twelve o'clock and grows it clockwise. Its geometry is `ring` in
  `tokens.ts`, the one set of real numbers there.
- `<Countdown>`'s `onExpire` must be referentially stable or the tick effect
  re-subscribes every render; `DiscussionScreen` wraps it in `useCallback`.
- Interpolating with a variable named `count` triggers i18next pluralisation.
  Use `current`/`total` unless plural forms are wanted.
- CSS uses `100dvh`, not `100vh`, and pads with `env(safe-area-inset-*)`;
  `index.html` sets `viewport-fit=cover` to make that meaningful.
- Text that swaps in place has a reserved `min-height` (`--size-line-reserved`);
  a disabled piece reads `--cut`/`--muted` from the surface it sits on.

## Out of scope on purpose

Voting, scoring, elimination, per-player word sets, network play, sound. Ask
before adding any of them. Multiple spies *is* supported.
